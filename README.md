# Ignis | 个人知识扩展平台

Ignis 是一个致力于帮助用户通过“知识微火”（Daily Sparks）和深度 AI 讨论来扩展知识边界的现代、高端 Web 应用。

![Ignis Logo](https://img.shields.io/badge/Status-Project-success?style=for-the-badge&logo=fire)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

## 🌟 核心特性

- **发现引擎**：动态推送精选知识点，涵盖心理学、航天、哲学、经济学等多个领域。
- **AI 深度讨论**：集成 AI 助手，针对每个知识点提供实时的思维碰撞与深度解析。
- **进阶系统**：自动追踪你的学习进度。标记完成的知识点将自动归档，并激发系统推送全新的内容。
- **高端设计**：采用极简、护眼的浅色调学术风设计（Scholarly Aesthetic），配合流畅的微动效。
- **离线存储**：基于 LocalStorage 的持久化技术，保证你的学习进度永远不会丢失。

## 🚀 快速开始

### 本地运行
由于本项目采用纯原生技术栈，无需任何安装步骤：

1. 克隆仓库：
   ```bash
   git clone https://github.com/dMiaoww/ignis.git
   ```
2. 进入目录：
   ```bash
   cd ignis
   ```
3. 使用任意 Web 服务器启动（如 Python）：
   ```bash
   python -m http.server 8000
   ```
4. 在浏览器访问 `http://localhost:8000`。

## 🛠️ 技术栈

- **结构**: HTML5 语义化标签
- **样式**: CSS3 (变量、Flexbox、Grid、Neumorphism 阴影)
- **逻辑**: ES6+ JavaScript (原生面向对象类结构)
- **存储**: Browser LocalStorage
